# 🍋 Little Lemon iOS App

An iOS application built using **SwiftUI** that showcases a restaurant menu experience with onboarding, menu browsing, and user interface components.

---

## 📱 Features

* 🧭 Onboarding screens for new users
* 🍽️ Menu listing with food items
* 🔍 Clean and modern UI using SwiftUI
* 🧑 User profile screen
* 💾 Core Data integration for local storage

---

## 🛠️ Tech Stack

* **SwiftUI**
* **Core Data**
* **MVVM Architecture**

---

## 📂 Project Structure

* `Models/` → Data models (MenuItem, MenuList)
* `Views/` → UI screens (Onboarding, Menu, Home, Profile)
* `ViewModels/` → Business logic
* `CoreData/` → Persistence layer
* `Assets/` → Images and resources

---

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/vedant5102/littlelemon.git
```

2. Open the project in Xcode

3. Run on simulator or real device
